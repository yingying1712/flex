# An Entire Page

This project is a simple homepage layout built using HTML and CSS Flexbox, inspired by the Odin Project design mockup.  

The goal of this assignment was to replicate the provided design using modern CSS layout techniques—primarily Flexbox—to build a fully responsive webpage.
