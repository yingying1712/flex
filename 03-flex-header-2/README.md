# Another Header Style 

This assignment also involves using flexbox rules to create a webpage header style. It will look a bit prettier.  

Often with flexbox, it's necessary to add containers around elements to position them correctly. It's also helpful to seperate the items that go on the left and right sides of the header.  

Just like in the 02-flex-header exercise, it will be use nesting flex containers inside each other.
